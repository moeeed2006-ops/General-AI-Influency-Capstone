- **Capabilities:** Answers visitor questions regarding engineering background, AI skills, and featured technical projects.

---

## 3. AI Operating System & Workflow Document

### Core AI Tool Stack
- **Primary LLM Assistants:** Google Gemini & Claude (Architectural reasoning, complex coding, and structured drafts)
- **Agent & Widget Platform:** Chatbase (Custom persona configuration, knowledge base training, and website widget integration)
- **Local / IDE Tools:** VS Code (HTML/Tailwind CSS deployment) & GitHub
- **Hosting & Deployment:** Vercel (Static site hosting and automated GitHub deployment pipeline)

### Daily AI Handoff Workflow Map
1. **Context & Intent Definition:** Define precise project requirements, constraints, and target schema before prompting.
2. **Knowledge Base Ingestion:** Supply clean context (resume details, project technical scopes, and background notes) into Chatbase to train the interactive agent.
3. **Execution & Code Integration:** Generate responsive layout code using Tailwind CSS, inject Chatbase widget scripts, and verify script placement.
4. **Human Judgment & Deployment Audit:** Audit agent response accuracy, verify live Vercel deployments across devices, and check console log execution.

---

## 4. Human Judgment & Quality Audit Checklist

Before any AI-generated output or deployment is published, it must pass this 5-point evaluation checklist:

- [x] **Technical Accuracy & Execution:** Does the code compile cleanly on Vercel without build errors or missing dependencies?
- [x] **Context Integrity:** Has all generic template text been replaced with authentic personal project details?
- [x] **Agent Accuracy:** Does the Chatbase agent answer queries accurately based strictly on trained knowledge sources?
- [x] **Voice & Tone:** Is the portfolio text clear, direct, and free from artificial fluff or robotic phrasing?
- [x] **Deployment Security:** Are secret keys hidden and public embed widgets properly scoped?
